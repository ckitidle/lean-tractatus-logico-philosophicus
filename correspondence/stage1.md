# 段階 1 の対応記録

形式化した命題ごとに、Lean で何を言ったかを日本語で読み直し、論考とのずれを記録する(`docs/policy.md` §6 レベル 3)。
原文はここには載せない(本文を GitHub に上げない方針)。原文を差し込んだ読む用の版は `lake exe render-correspondence 1` で `out/correspondence/stage1.md` に生成する。

各項目:

- **Lean**:対応する宣言(ファイル)
- **読み直し**:Lean の言明を日本語で言い直したもの
- **ずれ**:形式化で失われたもの、付け加わったもの
- **性格**:定理の場合、「定義の展開」(定義を開けばすぐ成り立つ。中身は定義=解釈の側にある)か「中身あり」(定義から自明でない推論を要する)か(`policy.md` §3.4)
- **解釈**:`analysis/interpretation.md` の該当する論点
- **1933 年版**:第2刷での本文の違い。第2刷の本文が手元にないので、今のところすべて未確認

レビュー:パイロット分(2.04〜2.063、4.2、4.27、4.42、4.46、5.101)の読み方は、2026-11-06 にユーザーが了承した。特に、2.061 を「どの組み合わせも可能」と強く読むこと、2.063 を一対一の対応と読むこと、4.46 をすべての割り当てについて定義すること(段階 3 の色の問題で見直す前提)。

形式化の前提(全体に共通):

- 事態(*Sachverhalt*)は、正体に立ち入らず「事態の型」として外から与える(5.557。`analysis/interpretation.md` の elementary_forms)
- 「論理空間」は、事態の成立・不成立の割り当てのうち「可能なもの」の集まりとして導入した。原文にこの形の定義はなく、1.13・2.11 などの「論理空間」をこう読むという設計上の選択である

### 2.04

- **Lean**:`Tractatus.World`(定義、`Tractatus/LogicalSpace.lean`)
- **読み直し**:世界とは、事態の集まりのうち成立しているものの集合のことである、と定義した
- **ずれ**:
  - 1.1 は世界を「事実の総体」とし、2.04 は「成立している事態の総体」とする。ここでは後者に揃え、事実(複合的なもの)は扱っていない
  - 原文の「総体」(これで全部)という含みは、集合として与えることに自動的に含まれる。全体性を別の事実として立てる読み方(論点 totality)は採っていない
- **解釈**:world_reality、totality
- **1933 年版**:未確認

### 2.05

- **Lean**:`Tractatus.nonexistent_eq_compl`(定理、`Tractatus/LogicalSpace.lean`)
- **読み直し**:世界(成立している事態の集合)が与えられれば、成立していない事態はちょうどその補集合である
- **ずれ**:原文の「決定する」を、「成立していない事態の集まりが、世界の補集合として一通りに決まる」と読んだ
- **性格**:定義の展開。世界を集合と定義した時点で、成立していない事態は補集合として決まっている
- **解釈**:world_reality
- **1933 年版**:未確認

### 2.06

- **Lean**:`Tractatus.Reality`(定義、`Tractatus/LogicalSpace.lean`)
- **読み直し**:現実とは、すべての事態について、成立している(真)か成立していない(偽)かを割り当てたものである。成立が肯定的事実、不成立が否定的事実に当たる
- **ずれ**:
  - 原文の「現実」は成立と不成立の「総体」だが、ここでは一つの割り当て(全事態についての成立・不成立の一覧)として表した
  - この割り当てを、4.3 の「要素命題の真理可能性」と同じものとして扱っている(4.3 の読みを先取りしている)
- **解釈**:world_reality
- **1933 年版**:未確認

### 2.061

- **Lean**:`Tractatus.Independent`(主張=仮定として使う条件、`Tractatus/LogicalSpace.lean`)。モデル:`Tractatus.Models.fullSpace_independent`(`Tractatus/Models/Stage1.lean`)
- **読み直し**:論理空間が「独立」であるとは、事態の成立・不成立のどの組み合わせも可能であることである。これは主張として、後の定理の仮定に置く
- **ずれ**:
  - 原文の「互いに独立」を、二つずつの独立ではなく「全部の組み合わせが可能」という強い形で読んだ。4.27 の「すべての組み合わせが成立しうる」と合わせた読みである
  - モデル:すべての割り当てを可能とする論理空間はこの条件を満たす。つまり、この主張は矛盾していない(どんな事態の型についても満たすものがある)
- **解釈**:independence
- **1933 年版**:未確認

### 2.062

- **Lean**:`Tractatus.no_inference_between_atomic_facts`(定理、`Tractatus/LogicalSpace.lean`)。反例のモデル:`Tractatus.Models.inference_possible_without_independence`(`Tractatus/Models/Stage1.lean`)
- **読み直し**:論理空間が独立だと仮定する。このとき、異なる二つの事態 a・b と、成立・不成立のどの値の組についても、「a がその値をとる可能な現実では、必ず b もその値をとる」ということはない
- **ずれ**:
  - 原文の「推論できない」を、推論の規則(証明の体系)についてではなく、「可能な現実のすべてで成り立つ結びつきがない」という意味の話として読んだ
  - 反例のモデル:独立でない論理空間(二つの事態が常に同じ値をとる)では、一方の成立から他方の成立が言える。つまり 2.062 の結論は、2.061 の主張がなければ出てこない
- **性格**:定義の展開。独立性を「全部の組み合わせが可能」と定義した時点で、ほぼそのまま成り立つ。中身は 2.061 の読みの側にある
- **解釈**:independence
- **1933 年版**:未確認

### 2.063

- **Lean**:`Tractatus.world_equiv_reality`(定理、`Tractatus/LogicalSpace.lean`)
- **読み直し**:世界(成立している事態の集合)と現実(全事態の成立・不成立の割り当て)は、ちょうど一対一に対応する
- **ずれ**:原文の「全体としての現実は世界である」という同一視を、文字どおりの同一ではなく「一対一に対応して、互いを決める」という意味で読んだ。これは解釈であり、別の読み方(現実の方が世界より多くを含む、など)もありうる
- **性格**:定義の展開に近い。集合と、要素かどうかの真偽の割り当てが対応することは、集合論の標準的な事実である
- **解釈**:world_reality
- **1933 年版**:未確認

### 4.2

- **Lean**:`Tractatus.Sense`(定義、`Tractatus/TruthPossibility.lean`)
- **読み直し**:命題の意味(*Sinn*)を、その命題と一致する現実(真理可能性)の集合として表した
- **ずれ**:
  - 原文の「一致と不一致」は、集合に入るか入らないかで表される
  - この表し方では、真になる条件が同じ命題は同じ意味を持つことになる(意味の外延化)。これは 5.141 と整合するが、意味の内包的な側面(同じ条件を別の仕方で言うこと)は失われる
- **解釈**:extensionality
- **1933 年版**:未確認

### 4.27

- **Lean**:`Tractatus.card_possible_of_independent`(定理、`Tractatus/TruthPossibility.lean`)
- **読み直し**:事態が有限個(n 個)で論理空間が独立なら、可能な現実の個数は、二項係数の和(ν を 0 から n まで動かした「n 個から ν 個を選ぶ選び方の数」の和)に等しい。この和は 2 の n 乗である
- **ずれ**:
  - 事態が有限個であることを仮定に置いた(原文も「n 個の事態」について述べている)
  - 原文の第2段落(「すべての組み合わせが成立し、他が成立しないことがありうる」)は、独立性の仮定として取り込んだ
- **性格**:中身あり(数え上げ)。ただし証明は Mathlib の補題(二項係数の和は 2 の n 乗)に大きく頼っている
- **解釈**:independence、infinity(有限に限ったこと)
- **1933 年版**:未確認

### 4.42

- **Lean**:`Tractatus.card_truthFunction`(定理、`Tractatus/TruthPossibility.lean`)
- **読み直し**:n 個の要素命題の真理関数(真理可能性の各行に真か偽を割り当てるもの)の個数は、二項係数の和(κ を 0 から 2 の n 乗まで動かした和)に等しい。これは 2 の(2 の n 乗)乗である
- **ずれ**:原文が数えているのは「命題が真理可能性と一致・不一致しうる仕方」で、ここでは「真理関数」の個数として数えた。真理関数一つと、それが真になる行の集まり一つが対応するので、数は同じになる
- **性格**:中身あり(数え上げ)。4.27 と同じく Mathlib の補題に頼っている
- **解釈**:extensionality
- **1933 年版**:未確認

### 4.46

- **Lean**:`Tractatus.IsTautology`、`Tractatus.IsContradiction`(定義、`Tractatus/TruthPossibility.lean`)
- **読み直し**:命題(その意味)がトートロジーであるとは、すべての真理可能性で真であることであり、矛盾であるとは、すべての真理可能性で偽であることである
- **ずれ**:「すべての真理可能性」を、論理空間の中の可能な現実ではなく、すべての割り当てとして定義した。独立性のもとでは両者は同じになるが、独立性が崩れる場合(段階 3 の色の問題)にどちらで定義するかは、改めて検討が要る
- **解釈**:independence
- **1933 年版**:未確認

### 5.101

- **Lean**:`Tractatus.TruthFunction`、`Tractatus.truthGrounds`(定義)、`Tractatus.card_truthFunction_two`(定理)(`Tractatus/TruthPossibility.lean`)
- **読み直し**:
  - 要素命題 n 個の真理関数を、5.101 の表のように、真理可能性の各行に真か偽を割り当てるものとして定義した
  - 真理関数の真理根拠を、それを真にする真理可能性の集まりとして定義した
  - 要素命題 2 個の真理関数はちょうど 16 個ある(5.101 の表の 16 行)
- **ずれ**:
  - 表の各行と、Russell 式の記法による式(「p ⊃ q」など)との対応は形式化していない。式という構文を扱うのは段階 2 の課題
  - 「16 個」は原文に明記されていないが、表がちょうど 16 行であることに対応する
- **性格**:16 個の定理は中身あり(数え上げ)。ただし 4.42 の特別な場合で、最後は計算(2 の 4 乗が 16)
- **解釈**:extensionality
- **1933 年版**:未確認

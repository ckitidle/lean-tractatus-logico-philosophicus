『論理哲学論考』の形式化の結果を、段階をまたいでまとめる。命題ごとの記録は段階ごとのファイル(`stage1.md`〜`stage4b.md`)にある。方針は `docs/policy.md`、進め方は `docs/roadmap.md`。

このまとめと仕上げ(全体の見直し)は、2026-11-06 にユーザーが了承した。これで予定した作業はすべて完了した。

## 主な結果

### 中身のある定理

形式化した定理の多くは、定義を展開すれば出る(「定義の展開」)。論考の中身の多くは、定理よりも、どう読むか(定義)の側にある。その中で、証明に手間のかかる定理は次のとおり。

- **N 演算子の表現力**(5.5、4.5、段階 2):要素命題が有限個なら、どの真理関数も N の繰り返しで作れる。逆に、N で作った記号はみな要素命題の真理関数である
- **量化の N への翻訳**(5.52、段階 4a):対象が有限個で全てに名前があれば、量化(入れ子でもよい)を含む命題は、N と要素命題だけの命題に意味を変えずに書き換えられる
- **同一性の記号の消去**(5.53、段階 4b):量化のない範囲で、同じ対象を指す名前を一つに揃えれば、同一性の記号を含む命題は、同一性の記号なしの命題に意味を変えずに書き換えられる
- **数え上げ**(4.27、4.28、4.42、5.101、段階 1):真理可能性の数 2^n、真理関数の数 2^(2^n)、二つの命題の真理関数 16 個
- **1.21 は 2.061 より弱い**(段階 1):事態が有限個なら「一つずつ変えられる」と「どの組み合わせも可能」は同じだが、無限個だと違う(反例のモデル)
- **名前の意味から命題の意味が決まる**(3.318、4.024、4.03、段階 3)、**配置が意味を決める**(3.142)
- **確率 1/2**(5.152、段階 3):異なる二つの要素命題は互いに確率 1/2 を与える

### この読みでは不成立(2 命題)

- **5.152(確率)**:真理項を共有しない命題が互いに確率 1/2 を与える、という主張は、要素命題どうしなら成り立つが、一般の命題では成り立たない(p と「q または r」では 3/4)
- **6.3751(色)**:色の命題を要素命題とみなすと、色の排除は論理的不可能性(矛盾)にならない。二つの要素命題が排除し合う論理空間は、独立性(2.061)を満たさない。色の命題を要素命題の真理関数として分析すれば両立する(論考自身の解決の方向)

これは Wittgenstein が誤りだという主張ではなく、ここで置いた読み方のもとでの結果である。

### 独立性の役割

多くの結論(2.062、2.225、5.134、6.1221、6.37、6.375 など)は、事態の独立性(2.061)を仮定に置いて示した。このうち 2.062、2.225、6.37、6.375 は、独立性を外すと成り立たないことを反例のモデルで示した(`Tractatus/Models/`)。段階 1・2 の主張は、それぞれ一つのモデルで同時に満たせる(主張どうしは矛盾しない)。段階 3 では、色の排除の主張(6.3751)が、色の命題を分析すれば独立性と両立するモデルを示した。

## 段階をまたぐ限界

各段階の記録の「全体の所見」から、残った課題をまとめる。

- **対象の層と論理空間の層のつながりが細い**:対象と事態の体系(2.01〜2.034)と、論理空間・像・命題の層は、段階 3 で一部つないだ(可能な事態だけが成立しうる論理空間)。ただし、それを使う定理は少なく、独立性を仮定した定理はこの論理空間に移していない
- **意味のない文にも意味が与えられる**:名前が対象の形式の許さない場所に立つ文にも、真偽の条件が定義される(3.03)
- **論理的像の定義が空虚**:この形式化ではどの像も自動的に論理的像になる(2.182)。論理形式以外の写像形式(空間的な像など)を区別する手段がない
- **操作の一般論と N がつながっていない**:操作・形式列・数(段階 2)と、N による命題の組み立ては、型の上で別々である
- **数は Lean の自然数**:数は操作の指数だ(6.021)という考えは、操作の反復回数との対応の定理として表しただけで、数そのものは Lean の `Nat` を使う
- **有限の範囲だけ**:N は有限個の値に施す。量化は対象が有限個で全てに名前がある場合だけ。無限の場合(4d)は保留
- **同一性と量化を組み合わせていない**:同一性の記号は量化のない範囲でだけ扱った。変項の排他的な読み(5.532 以降)は 4c で保留
- **Lean の言明はすべて「語っている」**:示されるもの(語れないもの)は、メタ定理として表せる範囲でしか扱えない(`docs/policy.md` §8)

## 確かめ方

- **機械的な検査**:`lake test -- --strict` が、証明が全て通っていること、札(命題番号)と分類の対応、余計な公理がないこと、記録の形式を確かめる
- **ブラインド逆翻訳**:各段階の終わりに、docstring と札を取り除いた Lean のコードだけを別のエージェントに渡して日本語で読み直してもらい、記録の読み直しと比べた。食い違いはどの段階でも見つからなかった。弱い定理や隠れた仮定の指摘は、直すか記録に書いた
- **ユーザーのレビュー**:各段階の始め(分類)と終わり(記録)にユーザーが確認した

## 1933 年版(第 2 刷)について

全ての記録で「1933 年版」の欄は「未確認」のままである。1933 年の第 2 刷では、Wittgenstein による訂正がドイツ語原文と英訳の両方に入っている(`source/README.md`)。しかし第 2 刷の本文が手元になく、1922 年版との違いを確かめられていない。欄は、第 2 刷の本文が手に入ったときに埋められるように残してある。形式化は 1922 年版(Project Gutenberg #5740)の本文に基づく。

## 原文と並べて読むには

記録には原文を載せていない(本文を GitHub に上げない方針)。手元で `source/` の本文データを作ったうえで、`lake exe render-correspondence <段階>`(段階は 1、2、3、4a、4b)を実行すると、原文(英語・ドイツ語)を差し込んだ版が `out/correspondence/` にできる。

## 段階 4b 全体の所見

- **中身のある定理は 4.241 と 5.53 の二つ**:
  - 4.241:二つの名前が同じ対象を意味することと、どの命題記号でも一方を他方に置き換えて意味が変わらないことが、同値である。逆向き(置き換えられるなら同じ対象)は、要素命題の意味が描く事態を決めること(異なる事態の要素命題は意味が違う)から出る
  - 5.53・5.531:同一性の記号を含む命題記号は、同じ対象を意味する名前を一つに揃えれば、同一性の記号なしの命題記号に翻訳でき、意味が保たれる。式の組み立てに沿った帰納法
- **「a = b」は世界について何も言わない**(4.242):真偽は名前の意味(解釈)だけで決まり、現実によらない。だから、それを知らずに命題を理解することはできない(4.243)。この形式化では「=」の意味を最初からそう定義しているので、これらは定義の展開に近い
- **Russell の定義への反例(5.5302)は単純**:二つの対象がどちらも何の性質も持たない現実では、全ての性質と関係を共有するが、異なる

### 4.241

- **Lean**:`Tractatus.replaceName`(定義)、`Tractatus.eq_iff_replaceable`(定理)(`Tractatus/Identity.lean`)
- **読み直し**:
  - 定義:名前 a を名前 b に置き換える操作
  - 定理:結合の仕方が一つ以上あるとき、名前 a と b が同じ対象を意味することと、どの命題記号でも a を b に置き換えて意味(真になる現実の集まり)が変わらないことは、同値である
- **ずれ**:
  - 「a=b は a を b で置き換えられること」を、置き換えても意味が変わることがない、と読んだ。原文の「置き換えられる」は記号の規則(定義)の話で、ここでは解釈のもとでの意味の同一性として扱った
  - 「定義は記号の規則」という部分は形式化していない
  - 置き換えは a から b への一方向で、対象にする命題記号は同一性の記号を含まないもの(段階 3 の命題記号)に限った
- **性格**:中身あり(逆向きは、要素命題の意味が描く事態を決めることから出る)
- **解釈**:identity
- **1933 年版**:未確認

### 4.242

- **Lean**:`Tractatus.Interpretation.senseless_eq`(定理、`Tractatus/Identity.lean`)
- **読み直し**:どの解釈でも、「a = b」の意味はトートロジーか矛盾である(真偽が現実によらない)
- **ずれ**:
  - 「表記の便宜で、記号の意味について何も主張しない」を、世界について何も言わない(トートロジーか矛盾)と読んだ
  - 「a = b」の意味をこの形に定義したので、ほぼ定義そのもの
  - 種別を主張から帰結に変えた
- **性格**:定義の展開
- **解釈**:identity
- **1933 年版**:未確認

### 4.243

- **Lean**:`Tractatus.Interpretation.eq_self_not_significant`、`Tractatus.Interpretation.eq_depends_on_meaning`(定理、`Tractatus/Identity.lean`)
- **読み直し**:
  - 「a = a」はどの解釈でもトートロジーである。どの要素命題もトートロジーではないので、「a = a」は要素命題と同じ意味を持たない
  - 対象が二つ以上あり、名前 a と b が異なる記号なら、「a = b」がトートロジーになる解釈と矛盾になる解釈がある。だから「a = b」は、二つの名前が同じものを指すかを知らなければ理解できない
- **ずれ**:
  - 「要素命題でも意味のある記号でもない」を、トートロジーであること(意味を持たないこと)と、要素命題とは意味が違うこととして読んだ。「a = a」が記号として要素命題でないことは、型の違い(同一性は要素命題と別の作り方)で表されている
  - 種別を主張から帰結に変えた
- **性格**:定義の展開に近い
- **解釈**:identity
- **1933 年版**:未確認

### 5.53

- **Lean**:`Tractatus.elimId`(定義)、`Tractatus.sense_elimId`(定理)(`Tractatus/Identity.lean`)
- **読み直し**:
  - 定義:各名前を、それが意味する対象のために選んだ名前に置き換え、「a = b」を、選んだ名前が同じ記号ならトートロジー N()、違う記号なら矛盾 ~N() に置き換える翻訳
  - 定理:意味される対象ごとに名前を一つ選ぶ選び方(同じ対象を意味する名前には同じ名前を選び、選んだ名前は元と同じ対象を意味する)のもとで、翻訳した命題記号(同一性の記号を含まない)の意味は元の意味と同じである。翻訳の結果に現れる名前は、異なれば異なる対象を意味する
  - そのような選び方はどの解釈にもある(`Tractatus.exists_choice`。選択公理を使う)
- **ずれ**:
  - 原文は、最初から「異なる対象には異なる記号」という記法で書くことを提案している。ここでは、ふつうの記法(同じ対象に複数の名前がありうる)で書いた命題を、その記法に翻訳できることとして示した
  - 量化のない範囲だけを扱った。変項の排他的な読み(5.532 以降)は 4c
  - 定理の後半(翻訳の結果では異なる名前が異なる対象を意味する)は、選び方の条件からすぐ出る。翻訳が正しいこと(前半)とは別の付け足し
  - 「a = b」を翻訳先でトートロジーか矛盾に置き換えるとき、解釈(どの名前が同じ対象を意味するか)を使っている。翻訳は記号だけでは決まらず、名前の意味の知識が要る(4.243 と同じ点)
- **性格**:中身あり(式の組み立てに沿った帰納法)
- **解釈**:identity
- **1933 年版**:未確認

### 5.5302

- **Lean**:`Tractatus.SharesAllProperties`(定義)、`Tractatus.russell_identity_fails`(定理)(`Tractatus/Identity.lean`)
- **読み直し**:結合の仕方が一つ以上あり、二つの対象が異なるとき:
  - どの事態も成立しない現実では、二つの対象は全ての性質と関係を共有する(二つを入れ替えても、どの事態の真偽も変わらない。だから事態の真理関数で表される複合的な性質の真偽も変わらない)が、異なる
  - 二つの対象が性質を共有しない現実もある。だから「全ての性質を共有する」は現実によって真にも偽にもなる、意味のある命題である。同一性(4.242)はそうではない
- **ずれ**:
  - 「性質の共有」を、二つの対象を入れ替えても事態の真偽が変わらないこととして読んだ。関係(2 項以上の事態)も含む
  - 反例は一つの特定の現実(どの事態も成立しない現実)で示した
  - Russell の定義そのもの(高階の量化を使う式)は書いていない。「全ての性質の共有」を意味の上で定義した
  - 種別を主張から帰結に変えた
- **性格**:定義の展開に近い(具体的な現実を二つ示すだけ)
- **解釈**:identity
- **1933 年版**:未確認

### 5.531

- **Lean**:`Tractatus.elimId`(定義)、`Tractatus.sense_elimId`、`Tractatus.sense_and_eq`(定理)(`Tractatus/Identity.lean`)
- **読み直し**:
  - 5.53 の翻訳は、「f(a, b) . a = b」のような記号を、同一性の記号なしの記号に書き換える
  - 「f(a, b) . a = b」の意味は、a と b が同じ対象を意味すれば「f(a, a)」の意味と同じで、そうでなければ矛盾である
- **ずれ**:
  - 原文の他の例(「f(a, b) . ~a = b」を「f(a, b)」と書く、など)は個別には扱っていない。どれも 5.53 の翻訳の定理に含まれる
  - 「~a = b」を「f(a, b)」と書く例は、異なる名前が異なる対象を意味する記法(翻訳の結果)でだけ成り立つ。ふつうの記法では、a と b が同じ対象を意味すれば「~a = b」は矛盾になる
- **性格**:定義の展開に近い(個別の例の計算)
- **解釈**:identity
- **1933 年版**:未確認

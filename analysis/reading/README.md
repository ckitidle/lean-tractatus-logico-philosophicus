## 分類の方法

`classification.tsv` の列:

| 列 | 中身 |
|---|---|
| `number` | 命題番号。`source/tractatus.json` と同じ順に、全命題が1行ずつ並ぶ |
| `kind` | 種別(下表) |
| `stage` | どの段階で扱うか(`docs/policy.md` §2):`1`〜`3`、`4a`〜`4d`、`out`(形式化しない)、`basis`(形式化ではなく設計の根拠として使う)。種別が `elucid` / `out` なら必ず `out`。全命題の扱いの正はこの列 |
| `scope_note` | 形式化できる種別(`def` / `claim` / `conseq` / `notation`)なのに `out` / `basis` にした理由と、保留にした段階(`4c` / `4d`)の理由。それ以外は `-` |
| `confidence` | 種別の確信度:`high` / `mid` / `low` |
| `contested` | 解釈が分かれる論点の ID(`contested.tsv`)。なければ `-`。1命題に1つだけ付けている |
| `concepts` | その命題が使う概念の ID(下の「用語」) |
| `related` | 関係の深い命題 |
| `rationale` | その種別にした根拠と、形式化についてのメモ |

種別:

| kind | 意味 | Lean での行き先(予定) | 数 |
|---|---|---|---|
| `def` | 用語を導入・特徴づける | `def` / `structure` | 62 |
| `claim` | 実質的な主張。公理の候補 | structure・class のフィールド、または仮定 | 190 |
| `conseq` | 他の命題から帰結すると本文が示すか、明らかに導ける | `theorem` | 124 |
| `notation` | 記法の提案(真理表、N 演算子、同一性を使わない記法、数の定義など) | `def`(記法の実装) | 19 |
| `elucid` | 解明・比喩・例示・他の哲学者への批判 | 形式化しない(対応表に理由を残す) | 99 |
| `out` | 形式化の対象外(倫理・神秘・主体・死など) | 形式化しない | 32 |

確信度は high 219、mid 268、low 39。(数は段階 1〜3 の形式化で種別を直したあとのもの。2026-11-06)

### 分類の判断基準と限界

- **種別を付けること自体が解釈である**。特に `claim` と `conseq` の境目は、本文に「therefore」「hence」があるか、直前の命題から明らかに導けるかで判断した。形式化を進めると、`claim` としたものが他から導けるとわかることがある(その場合は `conseq` に直す)
- `claim` が 194 と多いのは、論考の大半が理由を示さずに断定する形で書かれているから。全部を公理にするわけではない。フェーズ D で、形式化の範囲に入る `claim` だけを選ぶ
- 一つの命題に定義と主張が混ざっている場合(2.021 など)は、形式化で主になる方を選び、根拠の欄に書いた
- 「Lean での行き先」は目安で、決めるのはフェーズ D

## 節ごとの要約と形式化の見通し

### 1・2.0x:世界と事態と対象(存在論)

- 世界=成立している事態の全体(1、1.1、2.04)、現実=成立と不成立の全体(2.06)、事態=対象の結合(2.01)、対象の形式=事態に現れる可能性(2.0141)
- 中心は **2.061「事態は互いに独立」** と、その帰結の 2.062。論理空間を「事態への真理値割り当ての全体」とする定式化の根拠になる
- 対象の単純性(2.02)、実体の議論(2.021〜2.0212)、対象の形式(2.0123〜2.0141)は、形式化の仕方を決めにくい。C で確認する
- **見通し**:形式化に最も向いている。事態の型を `Atom`、世界を `Atom → Bool`(または `Set Atom`)とする骨格が自然に出てくる。2.05・2.062 は短い定理になる

### 2.1〜2.225:像の理論

- 像=要素の特定の結合という事実(2.14、2.141)。写像形式・論理形式(2.15〜2.18)。像の意味(Sinn)と真偽(2.221、2.222)
- 2.201「像は事態の成立・不成立の可能性を表す」により、像の意味を「可能世界の集合」として扱える
- 2.224・2.225「ア・プリオリに真な像はない」は、独立性のもとで「意味のある像は偶然的」という定理の候補
- **見通し**:像の「構造」「写像関係」(2.15〜2.1514)を構文と解釈の組として表すかどうかが設計の分かれ目。最小限なら意味論側(真理条件)だけで足りる

### 3:思考・命題・名前・記号

- 命題記号は事実(3.14)、名前は対象を意味する(3.203)、文脈原理(3.3)、完全な分析は一つ(3.25)
- 3.31〜3.318 の表現・命題変項、3.32〜3.344 の記号とシンボルの区別、3.33〜3.333 の型理論批判
- **見通し**:名前から対象への解釈関数、要素命題=名前の結合という構文論で表せる。ただし記号とシンボルの区別や論理的構文論(3.325〜3.334)は、Lean の型システムそのものとの関係を D で整理する必要がある(論点 `type_theory`)

### 4:命題・語ると示す・真理可能性

- 4.0x:命題は像、命題を理解する=真なら何が成立するかを知る(4.024、真理条件意味論)
- **4.0312「論理定項は代表しない」** が根本思想。4.0621 の ~~p=p、4.441「論理的対象はない」
- 4.1x:哲学論と、語る/示すの区別(4.12〜4.1213)。内的性質・形式的概念(4.122〜4.1274)
- **4.2〜4.46:真理可能性と真理条件**。要素命題(4.21〜4.26)、K_n=2^n(4.27)、L_n=2^(2^n)(4.42)、トートロジーと矛盾(4.46)
- **見通し**:4.2〜4.466 は最も形式化しやすい範囲で、定理の候補が集中している

### 5:真理関数・推論・確率・操作・一般性・同一性・独我論

- 5〜5.101:命題は要素命題の真理関数(外延性)、16 個の真理関数の表
- 5.11〜5.143:帰結関係を真理根拠の包含として定義(5.11、5.12)。ここから 5.122、5.14、5.141、5.142 などが導ける
- 5.15〜5.156:確率の定義(真理根拠の比)と、要素命題どうしは確率 1/2(5.152)
- 5.2〜5.32:操作・継続的適用・形式列。全ての命題は要素命題への真理操作の有限回の結果(5.32)
- **5.5〜5.52:N 演算子**。形式化の目玉になる表現的完全性の主張
- 5.53〜5.5352:同一性の記号を使わない記法
- 5.54〜5.5423:命題的態度と外延性
- 5.55〜5.5571:要素命題の形式はア・プリオリに決まらない(→ 事態の集合をパラメータにする根拠)
- 5.6〜5.641:独我論(対象外)
- **見通し**:5.1〜5.32 と 5.5〜5.52 が形式化の中心。量化(5.52)と同一性(5.53)は範囲を広げる段階で扱う

### 6:一般形式・数・論理・数学・科学・倫理

- 6〜6.01:命題の一般形式 [p̄, ξ̄, N(ξ̄)]
- 6.02〜6.03:数=操作の指数。Lean の `Nat.iterate` に当たり、6.241 の 2×2=4 の証明も再現できる

- 6.2〜6.241:数学は等式による方法
- 6.3〜6.372:帰納・因果・科学の法則(大半は形式化しない)。6.37・6.375「論理的必然性だけがある」は必然性=トートロジー性の根拠
- **6.3751:色の排除**。論考内部の緊張関係として定理化を試みる候補

## 読んでいて見つかったこと

1. **4.1252 の英訳の式の食い違い**:Ogden 訳(1922)の式「(∃x, y):aRx . aRy . yRb」は、ドイツ語原文の「aRx . xRy . yRb」と違う。4.1273 の英訳では正しく「xRy」になっているので、英訳の 4.1252 の誤りと考えられる。形式化ではドイツ語に従う。数式は OCR との突き合わせ(フェーズ A)から外していたので、そこでは見つからなかった
   - 教訓:数式を含む命題は、形式化するときに英独の両方を必ず見比べる
2. **Ogden 訳の訳語の揺れ**:「state of affairs」が Sachlage(状況)と Sachverhalt(事態)の両方に使われている箇所がある。「senseless」は unsinnig の訳で、4.461 の「without sense」(sinnlos)と区別が要る。概念 ID をドイツ語基準にしたのはこのため
3. **形式化に向いた範囲がはっきりしている**:2.0x(存在論)、2.2(像の真偽)、4.2〜4.466(真理可能性)、5〜5.156(真理関数・帰結・確率)、5.2〜5.32 と 5.5〜5.52(操作と N 演算子)、6〜6.03(一般形式と数)、6.1〜6.1271(論理)。定理の候補もここに集中している
4. **論考と Lean の論理の違いが表に出る箇所**:型理論の拒否(3.33〜3.333)、論理定項は代表しない(4.0312)、同一性の記号の消去(5.53)、形式的概念を関数で表せない(4.126〜4.1274)。Lean ではどれも「型」や「Prop の結合子」として当たり前に使うものなので、ずれとして D で明記する
5. **語る/示すの命題が 21 個ある**(論点 `say_show`)。形式化では、メタ定理(体系内の式では表せないことを体系の外から示す)として扱えるものと、限界として記録するしかないものに分かれる

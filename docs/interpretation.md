# 解釈の分かれ目と、形式化での扱い(フェーズ C)

`docs/reading/contested.tsv` に挙げた論点ごとに、二次文献の状況と、このプロジェクトでの扱いを決める。
文献は網羅的に読んだわけではない。形式化の設計に影響する範囲で、抄録・書誌・解説から確認した(2026-11-06)。全文を読めていない文献はそう書いてある。

基本方針:**解釈が割れるところは一つに決め打ちせず、仮定を外から差し込める形(パラメータや structure のフィールド)にしておく**。論考の主張は、その仮定を置いたときの定理として示す。

## 形式化の骨格に関わる論点

### independence:事態の独立性(1.21, 2.061, 2.062, 4.211, 4.27, 5.134, 5.135, 5.152)

- 文献:Suszko(1968)と Wolniewicz(1982)は、事態をブール代数の原子、可能世界をその極大元として扱う。独立性は「どの原子の組み合わせも可能世界になる」ことに当たる。Lokhorst も同じ系統の再構成をしている(PDF の本文は未読)
- **扱い**:論理空間を「事態への真理値割り当ての集合」として一般に定義し、独立性(2.061)を「その集合が全ての割り当てからなる」という仮定にする
  - 独立性を仮定すると、2.062・4.27・5.134・5.152 が定理になる
  - 仮定を外したモデルも作れるので、色の排除(下記)のような「独立性が崩れる場合」も同じ枠組みで扱える

### colour:色の排除(2.0131, 2.0251, 6.3751)

- 文献:6.3751 は、二つの色が同じ場所にあることを論理的に不可能とする。色の命題を要素命題とみなすと、要素命題の独立性(4.211)と衝突する。Wittgenstein 自身が 1929 年の「Some Remarks on Logical Form」でこの問題に向き合い、独立性の要請を見直した。これが論考の体系を離れるきっかけの一つとされる(後期への移行を断絶とみるか連続的な発展とみるかは論者で分かれる)
- **扱い**:論考の内部の緊張関係として、次を定理として示す
  - 独立性のもとでは、異なる二つの要素命題の論理積はトートロジーにも矛盾にもならない(6.3751 の括弧内の主張)
  - したがって、互いに排除し合う二つの命題(色の命題)は、両方が要素命題ではありえない
  - 論考自身の解決(色の命題は要素命題ではなく、さらに分析される)と、1929 年の見直しは、記録として残す

### object_form / simples / relations:対象とその形式

- 文献:対象が個体だけか、性質や関係も含むかは古くから論争がある(単純な対象の具体例を Wittgenstein は挙げていない)
- **扱い**:対象の正体には立ち入らない
  - 対象(`Object`)と事態(`Atom`)を型のパラメータにする
  - 事態にどの対象が現れるかを表す写像(構成要素)を持たせ、対象の形式(2.0141)を「その対象が現れうる事態の集合」として定義する
  - 関係が対象かどうか(2.03、3.1432)は決めない。構成要素の写像が関係を含むかどうかはモデルの側の選択になる
  - 2.0124(全ての対象が与えられれば可能な事態も全て与えられる)は、この定義のもとでの短い定理として示す

### world_reality / totality:世界と現実(1.11, 1.12, 2.04, 2.06, 2.063)

- **扱い**:世界を「成立している事態の集合」(2.04)、現実を「各事態の成立・不成立」(2.06、真理値の割り当て)として別々に定義し、両者が一対一に対応することを定理にする。2.063「全体としての現実が世界」と 2.05・1.12 はこの対応の帰結として示す
  - 「これで全部」(1.11 の全体性)は、世界を集合として与えることにもともと含まれる(集合に入っていない事態は成立していない)。全体性を別の事実として持ち出す読み方は採らないことを記録する

### extensionality / logical_constants / general_form:命題は真理関数(5, 5.3, 5.41, 5.54)

- **扱い**:二つの層を分ける
  - **意味論の層**:命題の意味(Sinn)を「それを真にする真理可能性の集合」(真理根拠、5.101)とする。同じ真理関数になる命題は同一(5.41)なので、この層では命題を真理関数そのものとして扱う。論理結合子はこの集合の上の演算として定義し、対象や名前としては扱わない(4.0312、5.4)
  - **構文論の層**:命題記号を要素命題から真理操作で作られる帰納的な型として定義し、意味論の層へ解釈する
- 命題的態度(5.541、5.542)は外延性の例外に見える箇所だが、形式化の範囲外にする

### n_operator:N 演算子の表現力(5.5, 5.501, 5.502, 5.51, 5.52, 6, 6.001, 6.01)

- 文献:
  - Fogelin は、N だけでは多重量化の命題を作れないと批判した。Geach と Soames は、変項の値の決め方についての記法上の工夫で応答した。Fogelin は、その工夫は論考の要請を破り、一部の論理的命題が決定不能になる代償を伴うと再反論した
  - Cheung(2000)は、有限の定義域で N を唯一の基本操作とする量化理論が表現的に完全であることを証明した
  - Rogers & Wehmeier(2012)は、同一性を記号の同一性で表すことと N だけを使うことの両方を、別々にも同時にも、表現的に完全な一階論理として実現できると論じた(抄録の範囲で確認)
- **扱い**:段階を分ける
  - 要素命題が有限個で量化がない場合:「全ての真理関数は N の有限回の適用で作れる」(5.5、6.001)を定理として示す。ここには論争がない
  - 量化を含む場合(5.52):Rogers & Wehmeier の再構成に沿って、範囲を広げる段階で扱う。Fogelin 論争は記録として残す

### identity:同一性の記号の消去(4.241〜4.243, 5.53〜5.5352)

- 文献:Hintikka(1956)は、包括的解釈の量化子と同一性で表せることは、弱排他的解釈の量化子で同一性の記号なしに全て表せることを示した。Wehmeier(2004)は弱排他的解釈を論考の読みとして最も適切とし、強排他的解釈については健全かつ完全なタブロー計算と、同一性付きの一階論理との相互解釈可能性を与えた(「On Ramsey's 'Silly Delusion'」)。Lampert & Säbel(2021)は、量化のない論理に限って、古典的な式が排他的記法の一つの式に必ずしも翻訳できないと批判している
- **扱い**:量化を扱う段階で、弱排他的解釈の意味論を定義し、同一性付きの通常の意味論との間の翻訳が意味を保つことを示す(5.533 の定理化)。それまでは記法の提案として記録する

### infinity:対象の無限性(4.2211, 4.463, 5.535)

- 文献:Lokhorst は 4.463 の「無限の論理空間」から、事態が無限にあることを要求すると読む
- **扱い**:事態の型 `Atom` に有限性を課さない。数え上げの定理(4.27、4.42、5.101)と N 演算子の有限の場合だけ、有限性(`Fintype`)を仮定に置く

### elementary_forms / analysis:要素命題の形式と分析(5.55〜5.5571, 3.25)

- **扱い**:要素命題の形式はア・プリオリに決まらない(5.557)ので、事態と要素命題の集合をパラメータにする根拠とする。日常の命題から要素命題への分析(3.25)は形式化しない。分析が済んだ後の命題、つまり要素命題の真理関数から始める

### number:操作の指数としての数(6.02, 6.021, 6.03, 6.241)

- **扱い**:操作の継続的適用(5.2521)を反復として定義し、数を反復の回数として扱う。6.241 の 2×2=4 の証明の手順を定理として再現する。Lean の自然数(`Nat`)を使うことと、論考が数を操作から定義することのずれは記録する

### logic_tautology:論理の命題はトートロジー(6.1, 6.11)

- **扱い**:トートロジーを意味論で定義する(4.46:全ての真理可能性で真)。「論理の命題」はトートロジーである命題のことと定義する。証明体系と完全性は扱わない(6.126、6.1262 の「証明は論理にとって本質的でない」とも合う)

## 論考と Lean のずれとして記録する論点

### type_theory:型理論の拒否(3.33〜3.333, 5.252, 6.123)

- 論考は Russell の型理論を退け、論理的構文論は記号の意味に触れずに成り立つべきだとする(3.33)。Lean はまさに型理論の上に立つ
- **扱い**:Lean の型は、論考を記述するための**メタ言語**の道具とみなす。論考の主張を Lean の型システムが体現しているとは主張しない。このずれを方針(`docs/policy.md`)に明記する

### formal_concepts:形式的概念(4.126〜4.1274)

- 論考は「対象」「数」などの形式的概念を関数(述語)ではなく変項で表すべきだとし、「対象がある」は無意味だとする。Lean では `Object` は型で、「対象がある」は `Nonempty Object` という命題として書けてしまう
- **扱い**:形式的概念を型として表すことは「関数で表さない」という点では論考に沿う。一方、型についての命題(`Nonempty`、濃度)を書けることは論考とずれる。メタ言語での記述として許し、ずれとして記録する

### say_show:語ることと示すこと(21 命題)

- **扱い**:二つに分ける
  - メタ定理として表せるもの:4.1211(矛盾や帰結は構造が示す)は、帰結関係が真理条件から計算できること(決定可能性)として示せる。6.113(論理の命題は記号だけから真とわかる)も同様
  - 表せないもの:2.172、4.12、4.1212、6.522、7 など。形式化の限界として対応表に記録する
- そもそも、このプロジェクトの Lean の言明はすべてメタ言語での記述であり、論考が「示されるだけ」とするものを「語って」いる。これはプロジェクト全体の前提として方針に書く(→ ladder)

### ladder:梯子(6.54)

- 論考は自分の命題を最後には無意味と認めるべき解明とする。形式化はそれを「意味のある」命題として扱う
- **扱い**:プロジェクトの位置づけとして方針に書く。形式化は論考の再現ではなく、論考の一つの読み方のモデル化であり、そのことで論考の主張を損なうわけでも裏づけるわけでもない

## 形式化の範囲外とする論点

| 論点 | 理由 |
|---|---|
| substance(実体の議論、2.021〜2.025) | 背理法の議論の再構成に、対象の存在と命題の意味の関係のモデルが追加で必要。将来の課題として記録だけする |
| causality / induction(因果・帰納) | 経験科学の方法論についての主張。6.37・6.375(論理的必然性だけがある)だけは、必然性=トートロジー性として扱う |
| mathematics(数学の命題、6.2〜6.2341) | 6.02〜6.03 と 6.241 の数の扱いだけを形式化する |
| solipsism(独我論、5.6〜5.641) | 主体と世界の限界についての主張で、形式化の対象外 |
